# F05 云端：群名归一化

| 项 | 值 |
| --- | --- |
| 负责人 | A |
| 优先级 | P0 |
| 预估 | 2 人日 |
| 依赖 | F02 |
| 阻塞 | — |
| 标签 | area/cloud, p0, size/M |

## 背景

用户不会说准确群名。说"夜班""夜班组""上夜班那个群"要落到同一个群，说"家庭群"和"老家群"如果都存在就要反问。

## 做什么

三步解析：

1. **精确匹配**：统一去空格、去"群"字后缀后比对
2. **别名表**：`group_alias(group_id, alias)`，支持"老婆"→"家庭群"这类私人叫法
3. **模糊匹配**：编辑距离 ≤ 2 或包含关系，命中多个则反问

返回三态：`matched(group_id)` / `ambiguous([]group)` / `not_found`

## 不做什么

- 不引入向量检索
- 不让 LLM 直接决定 `group_id`（它会编）
- 不做拼音/同音字纠错（V1 再看真实语料）

## 验收标准

- [ ] 表驱动的 30 条语料用例，准确率 100%（语料由 C 提供）
- [ ] "夜班"在只有"夜班组"时命中；同时存在"夜班组"和"夜班群"时返回 ambiguous
- [ ] 命中多个时返回的 TTS 文本是"是夜班组还是夜班群？"，≤40 字
- [ ] 找不到时返回"你还没有这个群，要新建吗？"，不静默失败
- [ ] 解析耗时 P99 < 5ms

## 技术要点

```go
type Resolution struct {
    Status  string   // matched | ambiguous | not_found
    GroupID string
    Options []Group
}
```

- 别名表按设备隔离，A 的"老婆"不影响 B
- 反问后用户回"第一个"，需要保存一次短会话状态（TTL 30s）
- 语料来自 F10 的调优过程，持续补充进测试
