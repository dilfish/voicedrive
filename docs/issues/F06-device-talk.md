## 背景

没有按钮、没有唤醒词，模拟设备用回车充当"被唤醒"。同一份二进制能开多份，就是多个人。

## 做什么

- REPL 循环：`回车` 开始说话，`回车` 或静音 1.5s 结束（替换现在的定时 `-mic-duration`）
- 音频源二选一：麦克风（ffmpeg 管道）或 WAV 文件，都按 20ms / 640 字节上行
- `--mac` 不同即不同设备，同机可跑 N 份
- 保留 `-say` 文本注入，给 CI 用

## 不做什么

- 不做唤醒词识别（PC 上没有）
- 不做常开 VAD 模式（会让灵矽会话一直计费）
- 不做本地 Opus 编码（裸 PCM 已验证可用）

## 验收标准

- [ ] `echo | go run ./cmd/linx-emu -mic 0` 回车开始、回车停止，灵矽能识别
- [ ] WAV 模式与麦克风模式行为一致，切源只改一个参数
- [ ] 同时开 3 份（不同 `--mac`），各自独立会话，互不串音
- [ ] 说话期间 `Ctrl-C` 能干净退出，不留下 ffmpeg 子进程
- [ ] `-say` 仍然可用，且与 `-mic` 互斥时给出明确报错

## 技术要点

- 现在 `streamMic` 是定时采集，改成由 stdin 控制：读一行开始，读到 EOF 停止
- ffmpeg 用 `exec.CommandContext`，退出时 `Process.Kill()` + `Wait()`，避免僵尸进程
- 多开时日志加 `--mac` 前缀，否则混在一起看不懂
- 麦克风权限：macOS 首次会弹窗，README 里写清楚
