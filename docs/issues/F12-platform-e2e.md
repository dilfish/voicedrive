## 背景

三个人各做完自己的部分，不等于能演。要有一条命令把服务、mock、三个设备全拉起来，5 分钟内演完。

## 做什么

- `make demo`：起服务 + 起 mock + 起 3 个模拟设备（不同 MAC、不同日志前缀）
- 演示脚本（90 秒版）：
  1. 老王建群，听到口令
  2. 小李用口令入群
  3. 老王说一句，小李的设备响起老王原声
  4. 小李回一句，老王听到
  5. 演示打断：小李说话时老王的消息被静音
- 端到端验收清单（人工对照）
- 冒烟测试：一条命令跑完主链路，结果写 `report.json`

## 不做什么

- 不做 GUI
- 不做多机部署（同一台电脑多进程即可）

## 验收标准

- [ ] 干净环境（`git clone` + `make demo`）能直接跑起来，不需要额外配置
- [ ] 90 秒演示脚本全程无手动干预，重复 3 次结果一致
- [ ] 冒烟测试在 CI 通过，失败时打印可定位的日志片段
- [ ] 演示前有自检：端口占用、麦克风权限、数据库连接，缺一就明确报错

## 技术要点

- 三个设备的日志按 MAC 前缀着色/加前缀，现场看得清
- 演示时错开 1~2 秒，避免多实例同时出声混在一起
- `make demo` 退出时清理所有子进程（trap EXIT）
- 数据库用临时目录，每次从空开始，保证可复现
